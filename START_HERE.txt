       streamlit run app.py
       → http://localhost:8501

       python api.py
       → http://localhost:5000

    ⚡ Quick Start (Automatic):
       python quickstart.py

    📋 Batch Predictions:
       python batch_predict.py --input data.csv --output results.csv

       docker-compose up

🔧 QUICK FIXES FOR COMMON ISSUES
═══════════════════════════════════════════════════════════════════════════

"ModuleNotFoundError":
  → pip install -r requirements.txt --upgrade

"creditcard.csv not found":
  → Download from Kaggle and place in project root

"Port already in use":
  → streamlit run app.py --server.port 8502

"Out of memory":
  → Use undersampling (enabled by default) or reduce data size

"All predictions are Normal":
  → Check fraud probability scores (fraud is rare, ~0.17%)
