## ✨ Features

### 🎯 Core Functionality
- **Machine Learning Models**: 6 different algorithms trained and compared
  - Logistic Regression
  - Support Vector Machine (SVM)

  - Random Forest

- Fraud percentage analysis

## 🚀 Installation

### Prerequisites
- Python 3.8 or higher
- pip (Python package manager)

### Step 1: Clone the Repository
```bash
git clone https://github.com/iamparasghimire/credit-card-fraud-detection.git
cd credit-card-fraud-detection
```

### Step 2: Create Virtual Environment (Recommended)
```bash
# On macOS/Linux
python3 -m venv venv
source venv/bin/activate

# On Windows
python -m venv venv
venv\Scripts\activate
```

### Step 3: Install Dependencies
```bash
pip install -r requirements.txt
```

### Step 4: Download Dataset
Download the credit card fraud dataset from [Kaggle](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud):
- Place the `creditcard.csv` file in the project root directory

## 📖 Usage

### Option 1: Run Streamlit GUI (Recommended for beginners)
```bash
streamlit run app.py
```
The GUI will open at `http://localhost:8501`

**Steps in the GUI:**
1. **Home**: Upload your `creditcard.csv` dataset
2. **Data Analysis**: Explore data distribution and patterns
3. **Model Training**: Train all models with custom parameters
4. **Make Predictions**: Predict fraud on new transactions
5. **Model Performance**: View detailed evaluation metrics

### Option 2: Run Flask API (For integration)
```bash
python api.py
```
The API will run at `http://localhost:5000`

### Option 3: Use Python Script Directly
```python
from data_loader import load_data, preprocess_data
from model_trainer import ModelTrainer

# Load and preprocess data
data = load_data('creditcard.csv')
X_train, X_test, y_train, y_test, scaler = preprocess_data(data)

# Train models
trainer = ModelTrainer()
results = trainer.train_all_models(X_train, y_train)

# Evaluate
metrics = trainer.evaluate_best_model(X_test, y_test)
print(f"Accuracy: {metrics['accuracy']:.4f}")

# Make predictions
new_transaction = [[...features...]]
predictions, probabilities = trainer.predict(scaler.transform(new_transaction))
```

## 📡 API Documentation

### Health Check
```
GET /api/health
```
Response:
```json
{
  "status": "ok",
  "message": "API is running"
}
```

### Train Model
```
POST /api/train
Content-Type: application/json

{
  "data_path": "creditcard.csv"
}
```

Response:
```json
{
  "status": "success",
  "message": "Model trained successfully",
  "best_model": "random_forest",
  "metrics": {
    "accuracy": 0.95,
    "precision": 0.93,
    "recall": 0.91,
    "f1": 0.92,
    "roc_auc": 0.96
  },
  "all_models": [...]
}
```

### Make Predictions
```
POST /api/predict
Content-Type: application/json

{
  "transaction": [0.1, -0.2, 0.5, ..., 100.0]
}
```

Or for multiple transactions:
```json
{
  "transactions": [
    [0.1, -0.2, 0.5, ..., 100.0],
    [0.2, 0.1, -0.3, ..., 50.0]
  ]
}
```

Response:
```json
{
  "status": "success",
  "predictions": {
    "transaction_id": 0,
    "is_fraud": false,
    "fraud_probability": 0.15
  }
}
```

### Get Data Statistics
```
POST /api/data-stats
Content-Type: application/json

}
```

### Get Model Information
```
GET /api/model-info
```

## 🤖 Models

### Algorithms Included

| Model | Best For | Parameters Tuned |
|-------|----------|-----------------|
| **Logistic Regression** | Baseline, interpretability | Solver |
| **SVM** | Non-linear patterns | Kernel, C |

The system automatically selects the best performing model based on cross-validation scores during training.

## 📚 Dataset Information

### Kaggle Credit Card Fraud Dataset
- **Transactions**: 284,807
- **Frauds**: 492 (0.172%)
- **Features**: 30 PCA-transformed + Amount + Time
- **Class Distribution**: Highly imbalanced
- **Solution**: Undersampling in preprocessing

## ⚙️ Configuration

### Preprocessing Options
Edit `preprocess_data()` parameters:
```python
X_train, X_test, y_train, y_test, scaler = preprocess_data(
    data,
    test_size=0.2,           # Test set percentage
    use_undersampling=True,   # Balance classes
    random_state=40           # Reproducibility
)
```

### Model Training Options
```python
results = trainer.train_all_models(
    X_train, y_train, 
    cv=5  # Number of cross-validation folds
)
```
